Install guide

Extract one folder, enable the mod next to Harmony, and check one log line. About two minutes.

Requirements

  • Timberborn 1.1.2.4 or a compatible 1.1 build.
  • Harmony from the Steam Workshop, version 2.4.1 or newer, installed and enabled.
  • A Mods folder inside your Timberborn user folder, normally Documents\Timberborn\Mods. If it doesn't exist yet, start the game once or create it yourself.

The mod has been built and checked on Windows. If your Timberborn user folder is somewhere else, extract into the Mods folder there instead.

Install

  1. Close Timberborn

    Mods are loaded when the game starts, so quit it first.

  2. Download the zip

    Get the latest release from GitHub. Choose the file named like HungryPathing-X.Y.Z.zip under Assets, not the one called Source code.

    Download the latest zip

    File:

  3. Extract it into your Mods folder

    Right-click the zip, choose Extract All, and pick Documents\Timberborn\Mods. The result must look exactly like this, with manifest.json and the settings file side by side inside version-1.1:

    Documents\Timberborn\Mods\
  HungryPathing\
    version-1.1\
      manifest.json
      HungryPathing.cfg
      Scripts\
        HungryPathing.dll
      Needs\
        Need.Beaver.Hunger.blueprint.json
        Need.Beaver.Thirst.blueprint.json
    README.md
    LICENSE

    If you see HungryPathing\HungryPathing\version-1.1, the folder is nested one level too deep. Move the inner folder up.

  4. Start Timberborn and enable the mod

    Open the game's mod manager, make sure Harmony is enabled, enable Hungry Pathing, and restart the game if it asks you to.

Check that it works

Load a colony, let it run for a moment, then open the game log (see where to find it) and search for [HungryPathing]. You should see, in order:

[HungryPathing] <version> loading.
[HungryPathing] Settings read from ...
[HungryPathing] Simulation settings: Enabled=True Needs=Hunger,Thirst WarningHours=0 ...
[HungryPathing] Hooks installed (5/5).
[HungryPathing] Active. One summary line per in-game day follows while a game runs.
[HungryPathing] Needs in this game: Hunger: buffer 3h, decays 0.8/day so a full bar lasts 30h; Thirst: buffer 3h, ...

<version> is the version you installed, and the ... parts vary. Three of those lines are the ones to check:

Hooks installed (5/5).
All five of the mod's hooks attached to the game. Anything else means a game update moved one; see Troubleshooting.
Hunger: buffer 3h ... Thirst: buffer 3h
The three-hour buffer is in place for both needs.
Simulation settings: ...
The values the mod uses. In co-op, every player's line must read the same.

After each in-game day a summary line says how often each rule fired. It looks like this (an example from the test colony; your numbers will differ):

[HungryPathing] Day 319: trips started by rule: just-in-time 41, pre-fuel 87, builder job 3 (of 60 job checks), critical redirected 9. 2160 evaluations, 4 failed launches, 3104 path queries.
Beta

One 355-beaver colony has run the mod for 36 in-game days, nearly all as a BeaverBuddies host, and the one error found there is fixed. That is still one colony, and the newest changes haven't been played in a live colony yet. Try it on a copy of your save first, and if the mod says it switched off, please report it with the lines that follow the warning.

If something doesn't look right, head to Troubleshooting.

Settings

Everything lives in version-1.1\HungryPathing.cfg, plain key = value lines with comments. The defaults are the behavior described on the overview. The ones people are most likely to touch:

WarningHoursThe buffer. 0 uses the blueprints' 3 hours; any other value overrides it.
PreFuel, JustInTime, BuilderJobCheck, WorkTimeClosestFood, RedirectCriticalTripsEach rule on or off, to try them one at a time.
Diagnosticstrue logs one line per trip the mod starts. Verbose; useful for a first look.
Enabledfalse leaves the game's behavior untouched while the mod stays installed.

Restart the game after editing. The full list with tuning notes is in CONFIGURATION.md.

Using it in co-op

The mod changes what beavers decide, so it is part of the simulation.

Same version, same settings file, every player

Every player installs the same version of the mod, runs the same game version and uses an identical HungryPathing.cfg. At startup the log prints one Simulation settings: line; if two players' lines differ, their games will drift apart. The DailyReport and Diagnostics keys are the only ones that may differ.

For a first co-op session with this beta, load a single-player copy of the save first and read the log.

If a Hungry Pathing dialog says the mod switched off after an error, that computer now plays without the mod while the others may not. Tell the host: the host saves and hosts that save again, and every player joins it. The load turns the mod back on for everyone.

Updating

  1. Close Timberborn.
  2. Download the zip from the latest release, the same one the download button above gives. In co-op, every player updates to the same version.
  3. Extract it into the same Mods folder and choose Replace when asked about existing files. If you edited HungryPathing.cfg, keep a copy: the zip ships the defaults.
  4. Start the game and confirm Hungry Pathing is still enabled in the mod manager.

Nothing is stored in saves, so there's nothing to migrate.

Uninstalling

Disable the mod in the mod manager, or close the game and delete Documents\Timberborn\Mods\HungryPathing. Your saves are unaffected because the mod never writes to them. Beavers go back to the game's own behavior the next time you load.
